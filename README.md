- **技术栈：** React + Vite 前端，Capacitor 封装 Android App；后端使用 FastAPI。

- **App 代码：** 位于 `frontend/` 目录；Android 工程为本地生成的 Capacitor 工程。
- **下载地址：** 目前没有公开 APK、TestFlight 或其他下载地址，Debug APK 由组员梁悦文保存在本地。
