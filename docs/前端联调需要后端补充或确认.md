# 前端联调需要后端补充或确认

以下内容来自当前 Figma 交互流程与现有 FastAPI 接口的对照，前端已先保留页面入口，联调时请确认对应能力和接口形式。

## 需要补充或确认的接口

- 大厅讨论：消息列表、发送消息、未读数，以及消息的可见范围。
- Agent 私聊：会话列表、消息历史、发送消息、流式回复或轮询状态。
- 旅行需求：同行者个人需求的保存、查询、代填状态和共享摘要发布/撤回。
- 好友选择：邀请面板中的好友搜索、好友列表和可邀请状态。
- 记忆簿：记忆列表、单条记忆查看、纠正、授权范围和删除。
- 记账与分账：账单创建、账单列表、参与人、分摊状态和金额变更。
- 旅行高光：高光记录的创建、查询和编辑。
- 设置：个人资料、Agent 偏好、记忆使用权限等设置项。
- 版本撤销：设计稿中的“撤销这次调整”对应的版本恢复接口和权限规则。
- 行程调整确认：调整建议的确认、拒绝、费用确认状态，以及应用后版本信息的返回字段。

## 需要确认的现有接口行为

- `/api/v1/trips/{trip_id}/members/invite` 当前使用 `user_id`，请确认前端如何获得可选用户列表。
- `/api/v1/trips/{trip_id}/members` 返回成员基础信息；请确认是否会返回昵称、头像、需求完成状态和代填来源。
- `/api/v1/trips/{trip_id}/revisions` 可以读取版本记录；请确认前端展示所需的差异字段是否都在 `diff_content` 中。
- `/api/v1/ai/replan` 与 `/api/v1/ai/revise` 返回候选方案后，前端需要知道候选状态、费用信息、保留项和变更项的稳定字段。
- `/api/v1/trips/{trip_id}/ai-runs/{ai_run_id}/apply` 应用后，请确认是否返回新的行程详情或需要前端再次请求 `/trips/{trip_id}`。
- `/api/v1/map/poi`、`/api/v1/map/route`、`/api/v1/weather` 的查询参数和返回结构，请确认是否可以直接用于旅行世界页面，或前端先使用行程中的已保存数据。
- 统一错误响应中的 `code`、`msg`、`data` 字段，请确认哪些错误码需要前端展示专门的状态文案。
